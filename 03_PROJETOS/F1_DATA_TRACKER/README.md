# 🏁 F1 Data Tracker

## Visão geral

O F1 Data Tracker é um projeto acadêmico em planejamento, com a proposta de organizar informações relacionadas ao campeonato de Fórmula 1 em uma estrutura que facilite consultas e análises.

## Problema que pretende abordar

Informações sobre corridas, pilotos, equipes e resultados podem precisar ser reunidas e organizadas para facilitar a consulta e a análise histórica do campeonato.

## Objetivo

Desenvolver uma solução que permita estruturar informações do campeonato e servir como base para futuras análises de dados.

## Entidades previstas

- **Corrida:** informações sobre cada etapa do campeonato.
- **Piloto:** dados de identificação dos competidores.
- **Equipe:** informações sobre as equipes participantes.
- **Resultado:** posições e resultados associados às corridas.

## Tecnologias previstas

- Python para processamento e organização dos dados.
- Docker para explorar a execução do projeto em ambiente conteinerizado.

## Etapas planejadas

1. Definir a estrutura e os requisitos do projeto.
2. Implementar a organização e o processamento dos dados.
3. Validar os resultados obtidos.
4. Avaliar a conteinerização com Docker.
5. Documentar a solução e suas limitações.

## Status atual

Projeto em planejamento e desenvolvimento incremental. As funcionalidades descritas são objetivos previstos, não funcionalidades que já estejam necessariamente implementadas.

## Evolução futura

A documentação será atualizada conforme cada etapa for implementada e validada.
