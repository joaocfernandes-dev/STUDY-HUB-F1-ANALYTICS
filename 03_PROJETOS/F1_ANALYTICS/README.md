# 🏎️ F1 Data Analytics Pipeline

## Visão geral

Projeto acadêmico de análise de dados da Fórmula 1, com foco na construção de um fluxo de ingestão, transformação, organização e disponibilização de dados para análise.

## Objetivos

- Obter dados de fontes relacionadas à Fórmula 1.
- Organizar os dados em etapas de processamento.
- Aplicar transformações para melhorar a qualidade dos dados.
- Preparar informações para exploração e visualização.
- Apoiar análises de desempenho no automobilismo.

## Tecnologias utilizadas

- **Python:** implementação do fluxo de processamento.
- **pandas:** manipulação e transformação de dados.
- **CSV:** armazenamento de dados em arquivos.
- **Power BI:** visualização e análise dos dados.
- **Git e GitHub:** versionamento e hospedagem do código.

## Arquitetura

O projeto utiliza uma organização inspirada nas camadas bronze, silver e gold:

- **Bronze:** dados inicialmente ingeridos.
- **Silver:** dados tratados e organizados.
- **Gold:** dados preparados para análises e visualizações.

## Status

Projeto desenvolvido em etapas acadêmicas anteriores. Consulte o código-fonte e os resultados disponíveis no repositório original para conhecer a implementação completa.
