# 🎓 Certificados e formações complementares

Esta pasta será utilizada para organizar certificados, comprovantes de cursos e outras formações complementares relevantes para minha trajetória acadêmica e profissional.

## Organização

Os documentos poderão ser classificados por:

- Nome do curso ou formação.
- Instituição emissora.
- Data de conclusão.
- Área de conhecimento.

## Objetivo

Manter os comprovantes de formação organizados e facilitar a apresentação das qualificações adquiridas.

**Observação:** adicionar somente certificados reais e documentos que possam ser compartilhados publicamente com segurança.
